DeP10 Standard Macros Reference

Matches the style of the Pep/10 Reference. Covers stdmacro.pep, the syscall-backed macros defined in pep10os.peph, and the dstack.pep stack macros.

stdmacro.pep

Pulled in with .INCLUDELIB "stdmacro".

Macro Args Effect
ASLA2 / ASLA3 / ASLA4 / ASLA5 0 Shift A left by 2, 3, 4, or 5 bits (repeated ASLA).
ASLX2 / ASLX3 / ASLX4 / ASLX5 0 Shift X left by 2, 3, 4, or 5 bits.
ASRA2 / ASRA3 / ASRA4 / ASRA5 0 Shift A right by 2, 3, 4, or 5 bits (arithmetic).
ASRX2 / ASRX3 / ASRX4 / ASRX5 0 Shift X right by 2, 3, 4, or 5 bits (arithmetic).
ROLA2 / ROLA3 / ROLA4 / ROLA5 0 Rotate A left by 2, 3, 4, or 5 bits.
ROLX2 / ROLX3 / ROLX4 / ROLX5 0 Rotate X left by 2, 3, 4, or 5 bits.
RORA2 / RORA3 / RORA4 / RORA5 0 Rotate A right by 2, 3, 4, or 5 bits.
RORX2 / RORX3 / RORX4 / RORX5 0 Rotate X right by 2, 3, 4, or 5 bits.
CHARI 2 (operand, mode) Reads one byte from the memory-mapped charIn port, stores it to the given operand. Direct memory-mapped I/O (baremetal), not a syscall.
CHARO 2 (operand, mode) Loads a byte from the given operand, writes it to the memory-mapped charOut port. Direct memory-mapped I/O (baremetal), not a syscall.
LIBC 0 Expands to a printf implementation supporting %c, %h (hex, via @HEXO), %d (decimal, via @DECO), and %s (string, via @STRO) placeholders, plus %% and \ escapes.
MALLOC 0 Expands to a simple bump-pointer allocator. Precondition: A holds the number of bytes requested; must be the last statement in the program (defines the heap after it). Postcondition: X holds the pointer to the allocated bytes. This never frees; a version that does may be worth revisiting eventually.
SWAPAX 0 Swaps the values of A and X.
XCHGA 2 (operand, mode) Atomically (within one macro expansion) exchanges A with the value at the given operand.
XCHGX 2 (operand, mode) Exchanges X with the value at the given operand, using A as a temporary; A and X are both restored to their post-exchange values (not clobbered) except for the intended swap.
XNORA 2 (operand, mode) A <- NOT(A XOR operand).
XNORX 2 (operand, mode) X <- NOT(X XOR operand).
PUSH 2 (operand, mode) Pushes the value at the given operand onto the stack.

Syscall-backed macros (pep10os.peph)

These are not in stdmacro.pep, but each one is still generated as a macro the moment the underlying syscall is declared (LDWA <NAME>,i followed by SCALL $1,$2), so they're called with @NAME the same way as any other macro. Available when .INCLUDELIB-ing the OS image rather than running baremetal.

Macro Args Effect
DECI 2 (operand, mode) Reads a decimal integer from input, stores it at the given operand.
DECO 2 (operand, mode) Writes the value at the given operand to output in decimal. 16-bit only; there is no 32-bit equivalent yet (see Open item, below).
HEXO 2 (operand, mode) Writes the value at the given operand to output in hexadecimal.
STRO 2 (operand, mode) Writes a null-terminated string, given a pointer, to output.
SNOP 2 (operand, mode) No-op syscall (useful for testing the trap mechanism itself).

dstack.pep

Caller-side stack manipulation macros. Pulled in with .INCLUDELIB "dstack" before first use, since (unlike the callable arithmetic routines) macro definitions must be seen by the preprocessor before the @NAME invocation that expands them.

Macro Args Effect
DUP 0 Duplicates the top 16-bit word on the stack.
DROP 0 Discards the top 16-bit word on the stack.
SWAP 0 Swaps the top two 16-bit words on the stack.
DDUP 0 Duplicates the top 32-bit (high/low word pair) value on the stack.
DDROP 0 Discards the top 32-bit value on the stack.
DSWAP 0 Swaps the top two 32-bit values on the stack.

These only know about word/double-word boundaries on the stack, not the semantic contents of what's there, matching the high-word-low-offset convention used throughout DADD/DSUB/DDiv/UDDiv. None of them preserve NZVC in any meaningful way.

Open item

No 32-bit equivalent of @DECO exists yet. A draft UDPRINTD/DPRINTD pair has been written and verified against 7 cases including 0, a value spanning both words, max unsigned 32-bit, a negative value, and INT32_MIN; not yet reviewed with Prof. Howard or merged. This page will be updated once that lands.
